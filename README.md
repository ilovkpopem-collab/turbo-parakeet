# Random Task Generator

**Автор:** Виолетта Накохова

## Описание

Random Task Generator — это простое приложение с графическим интерфейсом (GUI) на Python, которое помогает разнообразить ваши дела. Оно случайным образом выбирает задачу из заданных категорий (учёба, спорт, работа) и сохраняет историю выбранных задач.

## Функциональные возможности

- ✅ Генерация случайной задачи по кнопке
- ✅ Фильтрация задач по типу (Учёба, Спорт, Работа или все)
- ✅ Добавление новых задач (с проверкой на пустое имя)
- ✅ Сохранение истории задач в JSON-файл (автоматическая загрузка при запуске)
- ✅ Очистка истории
- ✅ Хранение предустановленных задач

1. Убедитесь, что установлен Python 3.6+
2. Сохраните файл `task_generator.py` в любую папку
3. Запустите командой:
